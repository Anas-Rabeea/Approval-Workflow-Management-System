# Approval-Workflow-Management-System

### Project Idea :
In a company each employee have different requests to their managers , other departments .
Maybe the employee wants to have an early vacation , sick leave , promotion , other department approval on a purchase or requesting a higher salary.
This System will help to make this process easier as the employee will issue a 'request' to their managers or the intended entities so it saves time for them instead on manually requesting a meeting and now we can track their requests, follow each approval step, and see who is responsible for reviewing them.


### Tech Stack : 
Java 21 , Spring boot , Spring Data JPA using Hibernate , Spring Security ,PostgreSQL , Docker.
